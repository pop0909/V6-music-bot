# 音樂機器人點歌（Chrome 擴充功能）

在 YouTube / YouTube Music / Bilibili 一鍵把歌加入音樂機器人的佇列。這個倉庫裡的擴充功能預設連到本專案已設定的面板網址；若你自己架設，請先改 `manifest.json` 的 `host_permissions` 與相關檔案。

## 安裝（載入未封裝擴充功能）
1. Chrome 網址列輸入 `chrome://extensions`
2. 右上角打開「開發人員模式」
3. 按「載入未封裝項目」→ 選這個資料夾 `V6\chrome-extension`
4. 會自動開啟「選項」頁：貼上金鑰 →「儲存並測試」，看到 ✅（並顯示你的名字）就完成
   - **朋友**：金鑰向擁有者索取（每人一把，擁有者在網頁「成員管理」建立）
   - **擁有者本人**：用自己電腦上的 `token.txt`（分享包裡沒有這個檔案）
   （之後也可以在擴充功能圖示右鍵 →「選項」修改）

## 使用
- **影片頁按鈕**：YouTube 標題旁、B 站桌面版在工具列（點讚那一排；沒有工具列就放在標題下方獨立一列），會出現「🎵 加入機器人」與「下一首播」（Shift+點加入 = 下一首播）。加入後按鈕會短暫顯示「已加入」。B 站／YouTube 行動版與 Shorts 用右下角浮動按鈕。
- **整個清單**：YouTube 播放清單或 B 站合集／公開收藏夾頁面會出現「📋 加入整個清單」。右鍵清單連結也可以。
- **右鍵選單**：在任何 YouTube 或 Bilibili 影片連結（或影片頁空白處）按右鍵 →「加入音樂機器人」/「下一首播」
- **工具列彈出視窗**：顯示正在播放、進度、封面；可暫停、跳過、調音量，也可把目前分頁的影片或整份清單加入
- **快捷鍵**：Alt+P 把目前分頁的歌加入佇列，Alt+N 跳過正在播放的歌（可在 `chrome://extensions/shortcuts` 更改）
- 機器人休眠中時加歌會自動叫醒並加入你上次的語音頻道開播

## 注意
- 金鑰不要轉給別人；外洩時請擁有者在「成員管理」停用或重設那把金鑰（立刻生效）
- 擁有者的 `token.txt` 可以管理所有成員，絕對不要分享；外洩時改伺服器 `.env` 的 `EXT_TOKEN` 並重啟
- 點的歌會在佇列與播放紀錄顯示你的名字
- 單一影片與播放清單／合集都可以從擴充功能加入（清單會在背景解析，完成後會提示加入了幾首）
- 更新擴充功能檔案後，到 `chrome://extensions` 按重新載入，並重新整理 YouTube 分頁
