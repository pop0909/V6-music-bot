# 音樂機器人點歌（Chrome 擴充功能）

在 YouTube / YouTube Music 一鍵把歌加入 https://musbot.kdns.fr/ 機器人的佇列。

## 安裝（載入未封裝擴充功能）
1. Chrome 網址列輸入 `chrome://extensions`
2. 右上角打開「開發人員模式」
3. 按「載入未封裝項目」→ 選這個資料夾 `V6\chrome-extension`
4. 會自動開啟「選項」頁：貼上金鑰 →「儲存並測試」，看到 ✅（並顯示你的名字）就完成
   - **朋友**：金鑰向擁有者索取（每人一把，擁有者在網頁「成員管理」建立）
   - **擁有者本人**：用自己電腦上的 `token.txt`（分享包裡沒有這個檔案）
   （之後也可以在擴充功能圖示右鍵 →「選項」修改）

## 使用
- **影片頁按鈕**：youtube.com/watch 或 music.youtube.com 播放中時，標題旁會出現「🎵 加入機器人」與「下一首播」（Shift+點加入 = 下一首播）
- **右鍵選單**：在任何 YouTube 影片連結（或 YouTube 影片頁空白處）按右鍵 →「加入音樂機器人」/「下一首播」
- **工具列彈出視窗**：顯示正在播放、佇列數量、語音頻道；可把目前分頁的影片加入或設成下一首
- 機器人休眠中時加歌會自動叫醒並加入你上次的語音頻道開播

## 注意
- 金鑰不要轉給別人；外洩時請擁有者在「成員管理」停用或重設那把金鑰（立刻生效）
- 擁有者的 `token.txt` 可以管理所有成員，絕對不要分享；外洩時改伺服器 `/root/v6/.env` 的 `EXT_TOKEN` 並重啟
- 點的歌會在佇列與播放紀錄顯示你的名字
- 只接受單一影片網址（播放清單請用網頁面板的匯入）
- 更新擴充功能檔案後，到 `chrome://extensions` 按重新載入，並重新整理 YouTube 分頁
